internship

I interned at LogN Pacific. This page collects the Windows 11 STIG remediation scripts I wrote there and the threat hunt reports I produced.

STIG Remediations

WN11-AC-000005

Account lockout duration set to 15 minutes or more.

WN11-AC-000010

Bad logon attempts limited to three or fewer.

WN11-AC-000015

Bad logon counter resets after 15 minutes.

WN11-AC-000020

Password history keeps 24 passwords.

WN11-AU-000500

Application event log size set to 32768 KB or more.

WN11-AU-000505

Security event log size set to 5120000 KB or more.

WN11-AU-000510

System event log size set to 32768 KB or more.

WN11-AU-000515

Application event log access blocked for non-privileged accounts.

WN11-AU-000520

Security event log access blocked for non-privileged accounts.

WN11-SO-000005

Built-in administrator account disabled.
