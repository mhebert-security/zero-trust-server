zero-trust-server

A zero-trust HTTP/1.1 server in stdlib-only Rust — the software serving this very page.

  • HTTP/1.1 parsed and served from raw TCP sockets — no framework, no hyper
  • TLS 1.3 only, via rustls — never OpenSSL
  • every visitor solves a SHA-256 proof-of-work gate before one byte of content
  • no unsafe anywhere in the server code
  • session cookies HMAC-SHA256 · HttpOnly · SameSite=Strict
  • concurrency bounded at 128 · 5s read/write timeouts · per-IP rate cap
  • a structured audit-log line for every request
