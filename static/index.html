Matthew Hebert

The puzzle never asked who you are. It asked your browser to spend a few seconds proving you are not a script, then let you in. That is the whole point of the gate: proof without identity, no tracking on the way out.

This page rode in over an HTTP/1.1 server I wrote in Rust from the raw TCP socket up. The standard library and rustls are the whole dependency list. No framework, no database, no JavaScript once the puzzle is done. Hand rolling a web server in 2026 is a strange choice, and it is the choice this page makes.

Software that carries your data should be small enough to trust. Mine is. It is running right now, and it is open.
